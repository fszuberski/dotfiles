## Interaction style

- Default to consice responses. Elaborate only when complexity genuinly warrants it.
- If uncertain, say so explicitly rather than proceeding with low-confidence guesses.
- Do not summarize what you just did at the end of a response unless asked.

## Hard Constraints

- Never add secrets, tokens, or credentials to any file that will be committed.
- Never silence linter warnings with suppression comments without a written justification in the same commit message.
